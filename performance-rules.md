# Performance Rules

- Use CSS instead of JavaScript for basic animation.
- Animate transform and opacity rather than layout properties.
- Use `will-change` sparingly.
- Lazy-load WebGL, video, and heavy assets.
- Choose one hero effect per page and keep subsequent sections calmer.
- Leave whitespace around complex visuals.
- Keep microinteractions short: 200–300ms.
- Disable or simplify motion under `prefers-reduced-motion`.
- Use GSAP or a lightweight Lottie player only when advanced motion is genuinely required.
