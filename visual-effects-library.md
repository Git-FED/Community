# Visual Effects Library

Use effects only when they serve the page. Prefer CSS and keep one primary hero effect per page.

## Options
- Animated gradients, particles, waves, light rays, grain, and grid systems.
- Scroll reveals, parallax, pinned sections, and progress indicators.
- Hover microinteractions, focus states, short card tilts, and SVG line drawing.
- Typewriter or staggered text, Lottie, and SVG morphing where justified.
- Dynamic dark/light mode, bento layouts, skeleton loaders, transitions, and success feedback.
- Ambient audio/video and WebGL only as optional, lazy-loaded enhancements.

## Guardrails
Use transform and opacity for animation, keep microinteractions to 200–300ms, lazy-load heavy assets, and honor `prefers-reduced-motion`.
