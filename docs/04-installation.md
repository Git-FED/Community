# Element Installation

Use the official download page for current packages and mobile links: https://element.io/download

- **Browser:** open https://app.element.io; no installation is required.
- **Linux:** follow the official repository instructions; Debian/Ubuntu users may use the documented `element-desktop` package after adding the official repository.
- **Windows and macOS:** download the current desktop package from the official Element download page.
- **iOS and Android:** use the Element X links published on the official download page.
- **Nightly:** packages.element.io is for advanced users who accept unstable builds.

Back up encryption keys and verify devices according to the homeserver and client guidance. If keys are lost, encrypted history may not be recoverable.
