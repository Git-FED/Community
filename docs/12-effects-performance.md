# Effects & Performance Guide

Use an effects library as a menu, not a mandate: gradients, particles, parallax, reveals, microinteractions, SVG motion, theme transitions, loading feedback, audio/video, and 3D are available only when they improve comprehension.

## Rules
1. Use CSS for basic effects.
2. Animate transform and opacity.
3. Use `will-change` sparingly.
4. Lazy-load heavy assets.
5. Use one hero effect per page.
6. Preserve whitespace.
7. Keep microinteractions to 200–300ms.
8. Respect `prefers-reduced-motion`.
