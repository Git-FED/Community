# Universal Prompt: Turn Any GitHub Project Into a Standalone HTML Website

Turn my GitHub project into a complete, premium, eye-catching static website.

## Project input
- Repository URL: [PASTE GITHUB REPOSITORY URL]
- Or attach the project ZIP/repository files directly.
- Project name: [PROJECT NAME]
- Preferred brand colors: [OPTIONAL COLORS]
- Support link or support providers: [OPTIONAL SUPPORT LINKS]
- Main CTA: [OPTIONAL CTA]

## Instructions
1. Inspect the README, package metadata, documentation, release notes, license, examples, and existing structure.
2. Use the actual project purpose, features, safeguards, commands, and terminology.
3. Do not invent capabilities, integrations, pricing, security claims, metrics, users, or guarantees.
4. Preserve recognizable project branding while improving the presentation.
5. Adapt the layout to the project category.
6. Make every HTML file independently usable from `file://` with inline CSS and JavaScript and relative links only.
7. Create index.html, support.html, privacy.html, terms.html, accessibility.html, and 404.html with working cross-page navigation.
8. Include a theme system, reduced-motion support, keyboard focus, responsive layouts, and a visible support CTA.
9. Verify every page directly, click every navigation tab, check desktop/mobile layouts, and fix issues before delivery.

## Deliverables
Return every HTML file in full, plus a README section explaining local opening and any external resources.
